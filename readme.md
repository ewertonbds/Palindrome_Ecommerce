# 🖤 Palindrome — E-commerce de Moda Gótica & Estilosa

## 📌 Sobre o Projeto

**Palindrome** é um sistema de **e-commerce desenvolvido em TypeScript**, executado via **terminal**, que simula o gerenciamento de produtos de uma **loja de roupas estilosas com estética gótica**.

O projeto foi criado com foco em **organização de código**, **boas práticas de programação** e **estrutura modular**, servindo como base para o desenvolvimento de sistemas de comércio eletrônico mais completos.

---

## 🛍️ Contexto do E-commerce

A loja **Palindrome** é especializada em:

- Roupas góticas  
- Acessórios alternativos  
- Moda estilosa com identidade *dark*  
- Peças voltadas para um público alternativo e urbano  

O sistema permite o gerenciamento de produtos, simulando funcionalidades essenciais de um e-commerce, como:

- Cadastro de produtos
- Listagem de produtos
- Atualização de informações
- Remoção de itens

---

## 🧠 Objetivo do Projeto

Projeto simples em **TypeScript**, desenvolvido para treinar **Programação Orientada a Objetos (POO)**, utilizando:

- Menu interativo no terminal
- Sistema de cadastro e controle de produtos
- Estrutura inspirada em projetos acadêmicos da **Generation Brasil**

---

## 🧱 Estrutura de Classes

O sistema possui uma **classe mãe** e **classes filhas**, seguindo o conceito de herança:

### 🔹 Classe Base
- **Produto**

### 🔹 Classes Derivadas
- **ProdutoAcessorio**  
  *(ex.: anel, colar, acessórios alternativos)*

- **ProdutoVestuario**  
  *(ex.: camisa oversized, calça, peças de vestuário)*

---

## 🏗️ Arquitetura do Projeto

O projeto segue uma arquitetura inspirada no projeto **"Conta Bancária"** da Generation Brasil:

- **Repository (Interface)**  
  Responsável pelas assinaturas dos métodos CRUD

- **Controller**  
  Implementa as regras de negócio e armazena os produtos em um array

Essa separação facilita manutenção, leitura e futuras expansões do sistema.

---
